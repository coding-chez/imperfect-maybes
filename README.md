# imperfect maybes. 

> a little space for unfinished thoughts, quiet questions, and everything in between.

A minimalist, dark-purple journaling web application built using HTML, CSS, and Vanilla JavaScript.

## About

imperfect maybes. is a small digital sanctuary for thoughts that do not necessarily need an ending.

It allows users to write, categorize, search, and save little pieces of their thoughts in a simple and personal interface.

Created as a beginner-friendly frontend development project to practice core web development concepts.

## Features

- Create and save thoughts
- Organize entries into categories
- Generate random writing prompts
- Search saved thoughts
- Mark thoughts as favorites
- Delete entries
- Persist data using browser localStorage
- Responsive desktop and mobile layout
- Dark purple and lavender aesthetic

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## Getting Started

1. Clone the repository.

   ```bash
   git clone https://github.com/YOUR-USERNAME/imperfect-maybes.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` using Live Server or your browser.

4. Start collecting your imperfect maybes.

## Data Storage

Thoughts are stored locally in the user's browser through localStorage.

No account or external database is required.
